# Marca — Marcos Barbosa

Arquivos extraídos do vídeo oficial enviado pelo cliente. Cores, proporções
e composição originais preservadas — nada foi redesenhado ou recolorido.

| Arquivo | Uso |
| --- | --- |
| `logo-marcos-barbosa.webp` | Versão usada no site (fundo transparente, ~28 kB). |
| `logo-marcos-barbosa.png` | Original em PNG com fundo transparente, para materiais impressos e redes sociais. |
| `logo-mark.png` | Apenas o símbolo da casa — favicon e usos em espaço reduzido. |

Se o cliente enviar o arquivo vetorial (SVG/AI/PDF) da marca, substitua
`logo-marcos-barbosa.webp` e aponte o componente `src/components/Logo.tsx`
para o novo arquivo: nada mais precisa mudar.
